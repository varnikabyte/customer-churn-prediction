# Customer Churn Prediction

A machine learning project that predicts whether a customer is likely to churn (leave a service), using the Telco Customer Churn dataset.

## What it does
- Performs exploratory data analysis (EDA) on customer data
- Handles missing values and encodes categorical features
- Trains a classification model to predict churn
- Evaluates model performance using accuracy and other metrics

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib/Seaborn

## Dataset
Telco Customer Churn dataset (Kaggle)

## How to run
1. Clone this repo
2. Install requirements: pip install pandas scikit-learn matplotlib
3. Open code.ipynb in Jupyter and run all cells
